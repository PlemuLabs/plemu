# Plemu artwork and prompt set

Created with the built-in image-generation tool, not the CLI. All twelve original images were inspected and saved locally as optimized 1600 × 900 WebP assets in `public/art/`. The product renders all game titles and interface text separately. Source intermediates retained locally are ignored by Git.

## Featured worlds: exact prompts

### `public/art/starfall.webp`

Use case: stylized-concept. Create original widescreen 16:9 premium cinematic pixel art key art for a retro science-fantasy game called Starfall Protocol. A lone small astronaut with a coral red cloak stands on a dark rocky ridge in the lower right, watching a vast pale turquoise ringed planet above an alien teal forest and distant emerald monoliths. Atmospheric mist, ancient ruins, starfield, strong silhouette, exceptional composition. Restrained mint jade cream and deep navy palette, visible deliberate 16-bit pixel clusters, richly detailed but calm and mysterious. Main landscape fills image with center planet. No text, no logos, no interface, no watermark.

## Supporting worlds: exact prompt construction

Concatenate the following prefix, the scene paragraph for each asset, and the following suffix with a single space.

Prefix: Use case: stylized-concept. Original widescreen 16:9 premium cinematic 16-bit pixel art key art for an independent retro game.

Suffix: Deliberate visible pixel clusters and beautiful layered atmospheric composition, sophisticated mature color palette, premium editorial game cover art, consistent with a high-end retro gaming marketplace. Absolutely no text, lettering, logos, UI or watermark.
