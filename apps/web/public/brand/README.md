# Plemu pixel-face mark

Based on the user's supplied pixel-face artwork. Production mark rebuilt with symmetric orthogonal paths on a 28-unit grid, solid #B6D935 and transparent negative space. Header/footer use the SVG; site metadata uses the same favicon mark.

- `plemu-mark.svg`: scalable source.
- `plemu-logo.png`: 1120 × 1120 RGBA transparent PNG, exported from the production SVG.

ImageGen built-in was used for initial cleanup explorations. Those outputs retained unwanted texture and were not used in production. The final production asset is the geometric SVG reconstruction and its PNG export; no CLI image-generation fallback was used.

Prompt brief: Refine the supplied friendly pixel face, preserving stepped outline, vertical eyes, wide smile and headphone-like sides; perfect bilateral symmetry, crisp square grid, uniform Plemu lime #B6D935, transparent background and interior negative space, no text, texture, gradients, shadows or stray pixels.
